# Portfolio de Thomas CHONGCHAREUN

## 📋 Description

Portfolio personnel conçu pour présenter mon parcours académique et professionnel dans le cadre de ma recherche de stage technicien (avril-juin 2026).

## 🚀 Utilisation

### Ouverture du Portfolio

1. Ouvrez le fichier `Portfolio.html` dans votre navigateur web
2. Cliquez sur le nuage pour accéder au site
3. Naviguez entre les différentes sections

### Structure du Site

- **Accueil** : Page d'introduction avec image de fond
- **Présentation** : À propos de moi
- **Valorisation** : Mes expériences et compétences (cliquez sur les cartes pour plus de détails)
- **CV** : Mon curriculum vitae consultable en ligne ou téléchargeable
- **Annexes** : Documents complémentaires

## 📁 Fichiers Requis

Pour que tous les liens de téléchargement fonctionnent, vous devez ajouter les fichiers suivants dans le même dossier que `Portfolio.html` :

### Obligatoires :
- `CV_Thomas_CHONGCHAREUN.pdf` - Votre CV au format PDF
- `Tableau_Valorisation.xlsx` - Tableau Excel de valorisation des expériences
- `Plaquette_Bachelor.pdf` - Plaquette de présentation du Bachelor
- `Lettres_Recommandation.pdf` - Vos lettres de recommandation

### Facultatifs :
- Remplacez les images placeholder par vos vraies photos :
  - Photo de profil (ligne 185)
  - Images des expériences (lignes 202, 210, 218, 226)
  - Image de fond de la page d'accueil (ligne 158)

## 🎨 Personnalisation

### Couleurs

Les couleurs sont définies dans les variables CSS (lignes 21-29) :
```css
--bg-main: #FBF8F3;      /* Fond crème */
--bg-secondary: #FFFFFF; /* Blanc */
--text-main: #3D405B;    /* Texte principal */
--primary: #81B29A;      /* Vert sauge */
--accent: #E07A5F;       /* Corail */
--highlight: #F2CC8F;    /* Jaune moutarde */
--cloud-blue: #BDE0FE;   /* Bleu pastel */
```

### Contenu

Tous les textes peuvent être modifiés directement dans le fichier HTML. Les données des expériences se trouvent dans l'objet JavaScript `experiences` (lignes 421-450).
